# Sistema de Validación – GOBES•eIDAS (España / Unión Europea)

Este módulo constituye la plataforma principal para la verificación de integridad, autenticidad
y correspondencia estructural del documento médico‑legal transfronterizo.

Incluye:
- index.html — Módulo oficial de validación
- styles.css — Estilos institucionales GOBES•eIDAS
- loader.gif — Indicador de validación (11 segundos)
- favicon.png — Identificador visual del sistema

Características:
- Validación con transición controlada
- Indicador de conectividad en tiempo real
- Compatibilidad total con iOS, Android y navegadores modernos
- Arquitectura autosuficiente, sin dependencias externas

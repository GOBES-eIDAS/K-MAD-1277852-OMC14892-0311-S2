# Plataforma Oficial de Verificación – GOBES•eIDAS  
(España / Unión Europea)

Este módulo constituye la plataforma principal de verificación del 
documento médico-legal transfronterizo (Certificado S2).

### Funciones principales
- Validar la integridad del documento original.  
- Confirmar la autenticidad estructural y digital.  
- Verificar la correspondencia de identificadores internos.  
- Supervisar el estado operativo del sistema GOBES•eIDAS.

### Elementos incluidos
- **index.html** — Página oficial del sistema de verificación.  
- **styles.css** — Estilos institucionales del entorno GOBES•eIDAS.  
- **loader.gif** — Secuencia animada de validación (11 s).  
- **favicon.png** — Identificador visual institucional.  

### Estado del certificado digital
El Certificado Médico-Legal S2 aparece como “verificado”, y su enlace 
de descarga está presente pero bloqueado hasta la finalización del 
proceso de firma digital eIDAS.
